\# Garry



A desktop assistant that wakes on a clap, greets you based on IST time, and speaks back.



Built from scratch as a portfolio project.



\## Status



\- \[x] Project initialized

\- \[ ] Clap detection

\- \[ ] Window UI

\- \[ ] IST greeting (text)

\- \[ ] IST greeting (voice)

\- \[ ] Auto-start on boot

\- \[ ] Packaged as .exe



\## Tech Stack



\- Python 3.14

\- CustomTkinter (UI)

\- sounddevice + numpy (audio)

\- pyttsx3 (speech)
